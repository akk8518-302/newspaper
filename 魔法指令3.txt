請讀取專案根目錄最新的 閱讀內容.pdf，使用既有的 template.html 公版，製作一篇全新的國小四年級深層閱讀互動網站。本次僅新增一篇課程，嚴格保留所有舊課程及既有公版，絕對不得覆蓋或刪除任何舊檔案。所有介面與提示文字務必使用台灣繁體中文。
核心執行步驟與功能規格：
一、 檔案讀取與頁面建置
1. 讀取與截圖嵌入： 分析 閱讀內容.pdf 的文章內容，並將文章原始內容截圖（保留原始排版樣貌），技巧性地嵌入新網頁中供學生對照閱讀。
2. 自動編號與首頁更新： 自動偵測專案中下一個尚未使用的 HTML 網頁編號並建立新檔案，同時自動更新 index.htm 首頁的課程清單。
3. 主題互動遊戲： 依據新文章的核心主題，設計一款適合國小四年級的互動小遊戲並融入網頁中。
二、 四層次閱讀理解選擇題（共 16 題）
1. 依據文章內容設計 16 題四層次閱讀理解選擇題，每題皆有 4 個選項（選項編號為 1、2、3、4）。
2. 每題皆須附上「正確答案」、「詳細解析」以及「文章依據」。
3. 答案分散設計： 請確保 16 題的正確答案選項號碼（1, 2, 3, 4）平均分散、不連續重複，讓學生無法靠猜測規律作答。
三、 「開放式思考題（深度探究）」與 50 字鼓勵防呆機制
1. 依據文章設計一題具深度的「開放式思考題（深度探究）」留言作答區（請確認畫面包含讓學生填寫「座號」與「姓名」的欄位，若 template.html 已有則沿用並確保能正確抓取）。
2. 有效字數計算（過濾空白）： 計算作答框字數時，請使用 text.replace(/\s+/g, '') 去除所有半形空白、全形空白與換行符號，防止小朋友按空白鍵湊字數。
3. 送出按鈕控制：
	• 當有效字數 < 50 字時，「送出」按鈕必須設為 disabled（無法點擊且外觀變灰）。
	• 同步攔截送出事件，若未滿 50 字嘗試送出，阻擋提交並跳出親切提醒：「你的思考很棒喔！不過還差 Y 個字才滿 50 字，再多寫一點你的想法吧！💪」。
4. 即時字數進度與鼓勵標語： 在輸入框正下方新增即時狀態提示區：
	• 未滿 50 字（0 ~ 49 字）： 顯示溫暖提醒色（橘色或深灰色），文字為：「目前寫了 X 個字，再多寫 Y 個字就能分享你的思考囉！加油，你可以的！✨」（X 為目前有效字數，Y 為 50 - X）。
	• 達到或超過 50 字： 按鈕恢復亮起可點擊狀態，提示文字轉為鼓勵的綠色，並顯示：「太棒了！你已經寫了 X 個字，想法好豐富，快按送出跟大家一起討論吧！🎉」。
四、 學習成績匯出與自動化內容評分（重要功能）
1. 在「學生匯出學習成績」的功能中，務必將「學生座號」、「學生姓名」以及「開放式思考題（深度探究）的完整作答內容」一併清楚顯示在匯出結果（如成績單畫面、下載的圖片或檔案）中。
2. 開放式思考題自動評分與等第： 請為開放式思考題設計前端 JavaScript 智慧評分邏輯（確保在 GitHub Pages 靜態網頁環境也能獨立運作），比對學生的作答內容是否包含「閱讀內容.pdf 的核心關鍵詞彙、因果邏輯與個人想法延伸」：
	• 自動計算並給出該題的分數與成績等第（例如：優等、甲等、乙等）。
	• 自動生成一段給小朋友的具體回饋評語，說明其想法是否有確實呼應文章內容。
五、 系統檢查、實測與回報
1. 路徑與相容性檢查： 檢查新舊網頁的所有功能、圖片相對路徑，確保部署至 GitHub Pages 時所有資源皆能正常載入不破圖。
2. 自動化瀏覽器實測： 完成後請啟動本地伺服器，在內建瀏覽器開啟新建立的課程網頁進行完整測試：
	• 測試選擇題作答與解析顯示。
	• 測試「開放式思考題」輸入 15 字（確認按鈕禁用並顯示還差 35 字）與輸入 55 字（確認按鈕亮起可送出）。
	• 測試「匯出學習成績」功能，確認座號、姓名、思考題作答、評分分數、等第與評語皆完整呈現。
3. 回報結果： 測試全數通過後，請告訴我新增網頁的檔名、index.htm 更新狀況以及各項功能測試結果。
